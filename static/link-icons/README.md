# Link service icons

Selected SVGs from [Simple Icons 16.33.0](https://github.com/simple-icons/simple-icons), downloaded from the published npm package. The SVGs are stored unmodified and served locally.

`SOURCES.json` records the versioned download URL, upstream source, and any per-icon license or brand-guideline metadata. `LICENSE.md` is the upstream package license; brand rights remain with their respective owners. See the [upstream disclaimer](https://github.com/simple-icons/simple-icons/blob/develop/DISCLAIMER.md).

The existing Google, GitHub, and Overleaf assets in `static/` are retained separately.
